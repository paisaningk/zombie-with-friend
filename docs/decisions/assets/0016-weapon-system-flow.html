ระบบ Weapon 3 ชั้น (template SO → synced WeaponSlot → runtime WeaponInstance) และ flow การซื้อ สลับ ยิง และ effect ระหว่าง client กับ host

3 ชั้นข้อมูล — ช่อง Primary (ตัวอย่าง: Shotgun + Explosive)

ชั้น 1Template
(static, แชร์)
WeaponData SO
stats only · id 1 = Shotgun
AttachmentData SO
modifier + effects · id 2 = Explosive
ซื้อ/แต่ง → server เขียนเลข id
ชั้น 2Synced
(owner-only)
SyncList<WeaponSlot> + activeSlot
ตัวเลขล้วน ข้ามเน็ต · { weaponId:1, mod:[2,-1,-1], ammo:6 }
OnChange → rebuild (ทำในทุกเครื่อง)
ชั้น 3Runtime
(cache/เครื่อง)
WeaponInstance[ ]
template=Shotgun · mods=[Explosive] · effects=[AoE] · profile={dmg48,pellets8,pierce0} · Ammo→อ่านชั้น2
ยิงอ่าน .profile · effect อ่าน .effects · HUD อ่าน .template/.mods — ก้อนเดียวจบ (ไม่แตก parallel cache)

Flow: กดยิง → โดน → effect

OWNER client
กดยิง → client-gate (ammo>0 + cooldown) → เดา tracer ให้ลื่น (predict)
╌╌╌ CmdReportHit(target, point, dir) ข้ามเน็ต ╌╌╌
HOST server
AUTH consume ammo (_slots[active].ammo--) + validate cooldown
HOST server
profile.damage → target.ReceiveHit() → คืน bool killed
HOST server
OnHitDealt: เดิน .effects → Explosive/Chain (damage เรียก ApplyDamage ตรง — กัน recursion)
HOST server
ถ้า killed → OnKill: Heal-Ammo on kill (local attribution — ปืนรู้เองว่าฆ่า)
╌╌╌ ObserversRpc → ทุกเครื่องเล่น FX (boom / สายฟ้า) ╌╌╌

Flow: ซื้อ / สลับ (สั้น)

OWNER
CmdBuyWeapon(id, slot) → HOST AUTH เช็ค ShopOpen+gold → _slots[slot] = {id, ammo:magSize, mod:[-1,-1,-1]} (เขียนทับทั้งก้อน → ammo reset atomic ไม่ค้าง)
OWNER
กด 1/2 → CmdSwap(slot) → HOST เซ็ต activeSlot + ช่องเดิม reloading=false (swap ยกเลิก reload · equip instant)
